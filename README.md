concrete is a sourcemod built on Mapbase that includes brand new levels and story separate from Half-Life 2. <br/>
-------------------------------------------------------------------------------------------------------------
concrete is planned to have realistic weapon handling, a bleak atmosphere, and custom weapons. <br> <br>
In order to play concrete, clone this repository into your steamapps/sourcemods folder and put the [Mapbase Content](https://www.moddb.com/mods/mapbase) found inside the content folders within mapbase_shared, mapbase_hl2, and mapbase_episodic within a folder titled "content" within the concrete directory. Also, the source-sdk2013-singleplayer must be installed via Steam.
